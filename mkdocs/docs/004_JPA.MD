# 04. JPA, audit, dan history

Modul `spring-common-jpa` menambahkan kolom audit standar, repository dasar, dan pencatatan
history otomatis ke tabel `<nama_tabel>_his` setiap kali baris diubah atau dihapus.

## Dependency

```groovy
implementation 'org.springframework.boot:spring-boot-starter-data-jpa'
implementation 'com.github.onevour.spring-commons:spring-common:<tag>'
implementation 'com.github.onevour.spring-commons:spring-common-jpa:<tag>'
runtimeOnly 'org.postgresql:postgresql'            // atau org.mariadb.jdbc:mariadb-java-client
```

Database yang didukung pembuatan tabel history: PostgreSQL dan MariaDB/MySQL.

## Entity dasar

| Kelas | Kolom |
|---|---|
| `BaseEntityCreated` | `is_deleted` (default `false`), `created_by`, `created_date` |
| `BaseEntity` (turunan di atas) | + `modified_by`, `modified_date` |

Kolom `created_*` dan `modified_*` diisi Spring Data Auditing. Aktifkan sekali di aplikasi:

```java
@Configuration
@EnableJpaAuditing
public class AuditConfig {

    @Bean
    public AuditorAware<String> auditorAware() {
        return () -> Optional.of("system"); // atau ambil dari SecurityContext
    }
}
```

Lalu entity:

```java
@Data
@EqualsAndHashCode(callSuper = true)
@Entity
@EntityHistory                                   // aktifkan history, lihat bawah
@EntityListeners(AuditingEntityListener.class)   // isi created_*/modified_*
@Table(name = "config")
public class Config extends BaseEntity {

    @Id
    @Column(name = "key", nullable = false, length = 50)
    private String key;

    private String value;
}
```

Entity dengan composite key memakai `@IdClass` dan `@Id` pada relasi `@ManyToOne`, contohnya
`CompanyFeature` di modul `spring-jpa-postgres-test`.

## History otomatis (`@EntityHistory`)

Untuk setiap entity ber-`@EntityHistory`:

1. **Saat aplikasi start**, `AuditTableCreator` memastikan tabel `<nama_tabel>_his` ada.
   Tabel dibuat dari struktur tabel asli, ditambah kolom `audit_id` (PK), `audit_type`,
   `audit_date`. Index non-PK ikut disalin. Jika tabel sudah ada, dilewati.
2. **Setelah UPDATE**, nilai *lama* baris disimpan ke `_his` dengan `audit_type = UPDATE`,
   atau `SOFT_DELETE` bila `is_deleted` menjadi `true`.
3. **Sebelum DELETE** (`repository.delete`), baris disimpan dengan `audit_type = HARD_DELETE`
   dan `is_deleted = true`.

INSERT tidak dicatat, karena nilai sebelumnya tidak ada. Kolom relasi koleksi
(`@OneToMany`, `@ManyToMany`) tidak ikut disimpan.

Jika penyimpanan history gagal, dilempar `AuditHistoryListenerException` sehingga transaksi
di-rollback. Perubahan data tidak akan pernah terjadi tanpa jejak history.

Contoh alur di `spring-jpa-postgres-test`:

```java
transactionService.createUser("jon");            // tidak ada history
transactionService.updateUser("jon", "name 1");  // user_his: UPDATE (berisi nilai sebelum diubah)
transactionService.deleteUser("jon");            // user_his: HARD_DELETE
```

## Repository

Pakai `JpaRepository` biasa, atau `BaseJpaRepository` bila butuh paging dengan `Specification`
tanpa menghitung total:

```java
public interface CompanyRepository extends BaseJpaRepository<Company, Long> {
    Optional<Company> findByNameAndDeletedFalseOrDeletedIsNull(String name);
}
```

```java
List<Company> page = companyRepository.findAll(spec, 0, 20, Sort.by("name"));
List<Company> page = companyRepository.findAllSpec(spec, PageRequest.of(0, 20));
```

`BaseRepository`, `BaseRepositoryImpl`, dan `BaseRepositoryFactoryBean` masih ada tetapi
`@Deprecated`. Jangan dipakai di kode baru.

## Membangun Specification

`BaseSpec` berisi helper untuk kelas Specification Anda:

```java
public class CompanySpec extends BaseSpec {

    public Specification<Company> search(String keyword, Long provinceId) {
        return (root, query, cb) -> {
            List<Predicate> p = new ArrayList<>();
            if (hasNotNull(keyword)) {
                p.add(cb.like(cb.lower(root.get("name")), paramLike(keyword.toLowerCase())));
            }
            if (isGTZero(provinceId)) {
                p.add(cb.equal(root.get("provinceId"), provinceId));
            }
            return cb.and(p.toArray(new Predicate[0]));
        };
    }
}
```

Helper: `hasNull`, `hasNotNull`, `paramLike`, `paramStartWith`, `paramEndWith`, `isGTZero`,
`isGTEqZero`, `distinctByKey`, `findDuplicateBySetAdd`.

## Soft delete

Kolom `is_deleted` disediakan, tetapi tidak difilter otomatis. Tambahkan kondisi di query
(`...AndDeletedFalseOrDeletedIsNull`) atau `@Where(clause = "is_deleted = false")` pada entity.

