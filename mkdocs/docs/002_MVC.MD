# 02. Model View Controller (MVC)

Pola yang dipakai: controller tipis, service mengembalikan `ServiceResolver`, converter
mengubah model domain menjadi model response. Semua response dibungkus envelope `Response`.

## Envelope response

Setiap response JSON berbentuk (`snake_case`):

```json
{
  "code": 200,
  "message": "success",
  "result": { "value": "OK" }
}
```

`errors` (map) hanya muncul bila diisi. HTTP status mengikuti `code`.

## Service

Turunkan dari `BaseService` dan kembalikan `ServiceResolver<T>`:

```java
@Service
public class SampleServiceImpl extends BaseService implements SampleService {

    @Override
    public ServiceResolver<User> findUser(String username) {
        User user = userRepository.findByUsername(username).orElse(null);
        if (user == null) {
            return error(ERROR_NOT_FOUND, "user not found"); // code 404
        }
        return success(user);                                // code 200, message "success"
    }
}
```

Helper yang tersedia di `BaseService`:

| Method | code | Keterangan |
|---|---|---|
| `success()`, `success(T result)`, `success(String message)` | 200 | |
| `created()` | 201 | |
| `success(int code, String message, T result)` | bebas | |
| `error()`, `error(String message)` | 500 | |
| `error(int code)` | code | pesan default untuk 400, 403, 404 |
| `error(int code, String message)`, `error(int code, String message, T result)` | code | |
| `validateValue(request)` | | lempar `ConstraintViolationException` bila Bean Validation gagal |

`ServiceResolver.isSuccess()` benar untuk kode 2xx.

**Jebakan overload**: `success("teks")` memanggil `success(String message)`, bukan `success(T result)`,
sehingga result-nya `null`. Untuk result bertipe `String` (atau tipe primitif/wrapper lain) pakai
`successNative("teks")`. Objek lain aman: `success(user)` mengisi result.

`BaseService` juga menyuntikkan `validator`, `restTemplate`, dan `mapper` (`ObjectMapper`)
sebagai field `protected`.

## Converter

Converter mengubah hasil service (`E`) menjadi model response (`T`). Daftarkan sebagai bean:

```java
@Component
public class SampleConverter extends ResponseConverter<User, UserResponse> {

    @Override
    public UserResponse convert(User user) {
        return BeanCopy.copy(user, UserResponse.class); // atau isi manual
    }
}
```

## Controller

Turunkan dari `BaseRestController`, lalu serahkan `ServiceResolver` ke `response(...)`:

```java
@RestController
@RequestMapping("/users")
public class UserController extends BaseRestController {

    @Autowired
    SampleService sampleService;

    // converter diisi otomatis oleh aspek @ConverterResolver (harus bean)
    @GetMapping("/{username}")
    public ResponseEntity find(@ConverterResolver SampleConverter converter,
                               @PathVariable("username") String username) {
        ServiceResolver<User> resolver = sampleService.findUser(username);
        return response(resolver, converter);
    }

    // alternatif tanpa aspek: converter di-autowire biasa
    @Autowired
    SampleConverter sampleConverter;

    @PostMapping
    public ResponseEntity create(@Valid @RequestBody UserRequest request) {
        return response(sampleService.create(request), sampleConverter);
    }
}
```

Variasi `response(...)` di `BaseRestController`:

| Method | Hasil |
|---|---|
| `response()` | `{code:200, message:"success"}` |
| `responseMessage(String)` | pesan kustom tanpa result |
| `response(T value)` | result tanpa converter |
| `response(resolver)` | result apa adanya dari resolver |
| `response(resolver, converter)` | result dikonversi; bila resolver error, envelope error dengan kode resolver |
| `response(resolver, ConverterClass.class)` | converter dibuat lewat konstruktor default |
| `responseEmptyResult(resolver)` | code dan message dari resolver, tanpa result |

Bila resolver error dengan `code == 200` atau `message == "success"`, nilainya dipaksa menjadi
500 / "error" supaya error tidak terlihat seperti sukses.

## Validasi

- Di controller: `@Valid` pada `@RequestBody` atau parameter query object, atau panggil `validateValue(request)`.
- Di service: `validateValue(request)`.
- Helper pengecekan ringan ada di `BaseValidator` (`isNullOrEmpty`, `isMinLength`, `isNew(id)`).

## ClientManifest (opsional)

Jika filter/interceptor Anda menaruh objek sesi ke atribut request `CLIENT_MANIFEST`, objek itu
bisa diterima langsung sebagai parameter controller selama kelasnya mengimplementasikan
`ClientManifest`:

```java
public ResponseEntity profile(UserSession session) { ... } // UserSession implements ClientManifest
```
